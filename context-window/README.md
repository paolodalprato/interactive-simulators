# Context Window Simulator

An interactive view of what may enter the context window when a new chat begins. The stack grows from the bottom upward, with the current user request at the top.

## 📥 Download

**[Download ZIP](https://github.com/paolodalprato/interactive-simulators/releases/latest/download/context-window-simulator.zip)** — Extract the archive, then open the single HTML file directly in a browser. No installation or network connection is required.

## 🎯 What You'll Learn

- Which instructions, project material, memory, and tool descriptions may be present at the first request
- Which elements are always present in this teaching model and which are optional
- How the same content occupies different shares of a 200K or 1M token window
- Why a tool's description can be present before its results exist

This simulator covers the **initial assembly** of context. Later conversation turns, compaction, summaries, and persistent memory behavior are separate topics.

## 🎮 How to Use

1. Turn optional components on or off. The platform instructions and user request remain selected.
2. Open each **i** button to see the component's source, owner, and role.
3. Switch between **200K** and **1M** token capacity to compare the space used.
4. Change between Italian and English using the language menu.

Token amounts are illustrative estimates, not measurements of a particular product. Exact context composition and ordering vary across platforms and APIs.
